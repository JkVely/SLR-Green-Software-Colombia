# Integration of multi-modal fusion and edge computing in smart elderly care system for intelligent buildings
## Abstract
> With the increasing aging of the population, the problem of old-age care is increasingly prominent. In China, 21.3% (Five-year prediction of the trend of deep aging), this study proposes a smart home-based elderly service system based on the intelligent building system. Pass "Three-dimensional linkage" Architecture (home—community—medical vertical continuity + security/environment/lighting horizontal integration + edge—cloud collaboration), integration Smoke Innovative technologies such as identification algorithm (misald alarm rate 0.7%) and enhanced learning lighting control (energy saving 35%).
