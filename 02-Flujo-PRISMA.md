# Flujo PRISMA

Cuadro de contadores PRISMA 2020. Actualizar al cerrar cada ronda de búsqueda.

| Etapa                                                                  | Número |
| ---------------------------------------------------------------------- | ------ |
| **1. Identificados** (registros localizados en todas las fuentes)      | `0`    |
| **2. Duplicados** (eliminados)                                         | `0`    |
| **3. Después cribado** (título y abstract)                             | `0`    |
| **4. Después elegibilidad** (texto completo evaluado contra criterios) | `0`    |
| **5. Incluidos** (estudios finales incluidos en la revisión)           | `0`    |

> **Notas para llenar:**
> - La columna "Identificados" suma los resultados de IEEE Xplore + Scopus + ACM DL +Google Scholar (complementaria).
> - Los duplicados se cuentan quita-repetidos entre todas las fuentes conjuntas.
> - "Después cribado" y "Después elegibilidad" se van restando según criterios de inclusión/exclusión definidos en `01-Criterios.md`.
> - "Incluidos" es el número que irá en el diagrama PRISMA final y en la tabla de características de `03-Matriz.md`.
